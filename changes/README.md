# Release-note fragments

Every user-visible change adds one file here: `changes/<short-slug>.md` with 1–3 sentences in **Dutch**, written for
players. The release workflow combines all fragments into the notes of the next version (shown in the app under
"Wat is er nieuw") and then deletes them. Use a unique name so parallel contributors never edit the same file.

Example `changes/wereldquiz-werelddeel.md`:

    Wereldquiz: kies nu bovenaan waar je wilt spelen – de hele wereld of alleen één werelddeel.
